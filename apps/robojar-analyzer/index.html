📖 RoboJar Analyzer - Complete User Guide

🚀 Getting Started

File Upload: Choose a RoboJar Excel report (.xlsx/.xls) using the Import button, or click "Load Test File" to try the analyzer with sample data.

Generate Charts: Click "Generate Charts" to automatically create visualizations for all four parameters (Mean Diameter, Mean Volume, Particle Count, Concentration).

Navigate Tabs: Use the parameter tabs to switch analyses. Each tab includes charts, statistics, and forecast metrics tailored to that measurement.

🤖 Understanding RoboJar Data

Mean Diameter: Average particle size in micrometers (µm). Key indicator of flocculation effectiveness.

Mean Volume: Average volume of particles—often tied to settling characteristics.

Particle Count: Number of particles detected per unit volume. Higher counts may indicate poor coagulation.

Concentration: Total particle concentration, typically expressed as volume percentage.

📊 Chart Configuration

Line Chart: Emphasizes trends over time with connected points.

Scatter Plot: Reveals outliers and distribution without connecting data.

Secondary Axis (RPM): Overlay paddle RPM to correlate mixing intensity with particle behavior.

🔮 Forecasting Methods

Adaptive: Adjusts polynomial order automatically and works best for changing trends.

Windowed: Focuses on the most recent stable window.

Weighted: Emphasizes newer data points.

Simple: Uses a traditional polynomial regression across all data.

Start Time & Window: Control how much history the forecast uses after an initial stabilization period.

⏰ Time Window Selection

Full Duration: Uses the entire dataset.

Steady State: Excludes the first 5 minutes to remove start-up effects.

Final 10 Minutes: Focuses on the most stable portion of the test.

Custom Range: Specify exact time bounds for bespoke analysis.

🧹 Filtering Options

Remove Outliers (IQR): Eliminates extreme values based on the interquartile range.

Smooth Data (Moving Average): Applies a 5-point moving average to limit noise.

Both: Remove outliers first, then smooth remaining data.

📊 Basic Statistics

Min/Max: Operational range.

Mean: Average value used for reporting.

Median: Middle value, less influenced by spikes.

Standard Deviation: Measures variability around the mean.

📈 Advanced Statistics

Coefficient of Variation: Normalized variability (standard deviation ÷ mean).

Percentiles (P10, P90): Typical operating range for the dataset.

Interquartile Range: Spread of the middle 50% of readings.

🔊 Noise Assessment

Noise Level: Uses CV and outlier detection to describe signal quality.

Low: CV < 15%
Medium: CV 15-30%
High: CV > 30%

🎯 Forecast Quality Metrics

R²: Variance explained by the forecast model; closer to 1.0 is better.

RMSE / MAE: Average prediction error in data units.

MAPE: Error expressed as a percentage for easy comparison.

💡 Best Practices

Validate raw data, focus on steady-state periods, confirm forecasts with metrics, and document any data conditioning applied.
